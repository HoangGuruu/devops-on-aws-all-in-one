# Kubernetes Cluster on EC2 - Terraform & Ansible Automation

Complete automation to build a production-ready Kubernetes cluster on AWS EC2 using Terraform and Ansible.

## Architecture

- **1 Master Node** (t3.medium) - Control plane
- **2 Worker Nodes** (t3.small) - Workload nodes
- **Container Runtime**: containerd
- **CNI Plugin**: Flannel
- **Kubernetes Version**: 1.28

## Prerequisites

1. **AWS Account** with appropriate permissions
2. **AWS CLI** configured with credentials
3. **Terraform** (v1.0+)
4. **Ansible** (v2.9+)
5. **SSH Key Pair** in AWS

## Step-by-Step Deployment

### Step 1: Configure AWS Credentials

```bash
aws configure
```

### Step 2: Configure Terraform Variables (Optional)

```bash
cd terraform
cp terraform.tfvars.example terraform.tfvars
```

Edit `terraform.tfvars` (optional, defaults are set):

```hcl
aws_region           = "us-east-1"
instance_type_master = "t3.medium"
instance_type_worker = "t3.small"
worker_count         = 2
key_name             = "k8s-cluster-key"        # Auto-generated
my_ip                = "YOUR_IP/32"             # Recommended: curl ifconfig.me
```

**Note**: SSH key pair is automatically created by Terraform!

### Step 3: Deploy Infrastructure (Terraform)

```bash
cd terraform
terraform init
terraform plan
terraform apply
```

This creates:
- VPC with public subnet
- Internet Gateway
- Security Groups
- 1 Master EC2 instance
- 2 Worker EC2 instances
- Ansible inventory file

### Step 4: Configure Kubernetes (Ansible)

```bash
cd ../ansible

# Test connectivity
ansible all -m ping

# Deploy Kubernetes
ansible-playbook playbook.yml
```

The playbook will:
1. Install containerd on all nodes
2. Install Kubernetes components (kubelet, kubeadm, kubectl)
3. Initialize master node
4. Install Flannel CNI
5. Join worker nodes to cluster

### Step 5: Verify Cluster

SSH to master node (command shown in Terraform output):

```bash
ssh -i ~/.ssh/k8s-cluster-key.pem ubuntu@<MASTER_IP>
```

Or use the output command:
```bash
terraform output ssh_command_master
```

Check cluster status:

```bash
kubectl get nodes
kubectl get pods -A
kubectl cluster-info
```

## Automated Deployment

Use the deployment script for one-command deployment:

```bash
chmod +x deploy.sh
./deploy.sh
```

**What gets automated:**
- ✅ SSH key pair creation
- ✅ EC2 instances provisioning
- ✅ Security group with all K8s ports
- ✅ Ansible inventory generation
- ✅ Kubernetes cluster setup
- ✅ CNI installation
- ✅ Worker nodes joining

## Access Cluster from Local Machine

Copy kubeconfig from master:

```bash
scp -i ~/.ssh/k8s-cluster-key.pem ubuntu@<MASTER_IP>:~/.kube/config ~/.kube/config-k8s-cluster
export KUBECONFIG=~/.kube/config-k8s-cluster
kubectl get nodes
```


## Troubleshooting

### Nodes not joining cluster

```bash
# On master
sudo kubeadm token create --print-join-command

# On worker
sudo kubeadm reset
sudo <join-command>
```

### Pods not starting

```bash
kubectl describe pod <pod-name>
kubectl logs <pod-name>
```

### Connectivity issues

Check security group allows:
- Port 22 (SSH)
- Port 6443 (Kubernetes API)
- All traffic between cluster nodes

## Security Notes

- Update `my_ip` variable to restrict SSH access
- Use IAM roles instead of access keys when possible
- Enable encryption at rest for EBS volumes
- Implement network policies in production
- Use private subnets for worker nodes in production
